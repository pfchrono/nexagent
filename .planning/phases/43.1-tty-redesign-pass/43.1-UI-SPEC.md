## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline delimiters and compact trace padding |
| sm | 8px | Tight intra-block spacing |
| md | 16px | Default block interior spacing |
| lg | 24px | Section spacing between reply/task/trace blocks |
| xl | 32px | Workspace-level vertical gaps |
| 2xl | 48px | Major state transition separators |
| 3xl | 64px | Reserved for full-screen mode transitions |

Exceptions: none

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.45 |
| Label | 12px | 600 | 1.35 |
| Heading | 16px | 700 | 1.30 |
| Display | 18px | 700 | 1.20 |

Contract notes:
- Assistant reply block uses `Heading` for block title and `Body` for content.
- Tool/trace items use `Label` + `Body`, never `Display`.
- Composer and footer use `Label` for metadata, `Body` for editable line.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B1118` | Workspace background, transcript background |
| Secondary (30%) | `#162230` | Block surfaces for reply/task/trace/composer |
| Accent (10%) | `#28C2A0` | Active reply marker, selected control, current-step emphasis |
| Destructive | `#D64545` | Error/blocker/cancel states only |

Accent reserved for: active reply boundary, selected control text, progress highlight, non-error confirmation marker.

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Continue execution |
| Empty state heading | No runtime activity yet |
| Empty state body | Start a prompt or run `/continue` to begin a tracked turn. |
| Error state | Runtime blocked. Review blocker detail and choose `/approval`, `/cancel`, or retry path. |
| Destructive confirmation | Cancel run: confirm cancellation and keep blocker visible in transcript. |

---

## Interaction Contract

- Transcript hierarchy order locked: `assistant reply` -> `current task` -> `recent work/trace` -> `composer`.
- Tool traces grouped by task boundary, not flat chronological dump.
- Blocker/error events always rendered above normal progress entries in summaries.
- Do not change runtime semantics in this phase; visual contract only.
- Donor influence rule: mirror clarity patterns, avoid direct visual copying from Hermes/free-code/codex-fresh.
