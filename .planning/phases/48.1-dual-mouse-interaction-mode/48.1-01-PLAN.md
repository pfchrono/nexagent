# Phase 48.1 Plan 01: Dual mouse interaction mode

## Objective

- **What:** Implement dual mouse interaction mode with deterministic mode persistence and conflict fallback UX.
- **Why:** Restore wheel scroll without sacrificing highlight-copy workflow.
- **Output:** Stable `auto|scroll|select` mouse mode pipeline integrated into TUI runtime.
